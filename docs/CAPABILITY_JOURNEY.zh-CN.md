2026-10-22：最终 0.2.4 ZIP 解压版的两项真实模型任务与界面检查均通过。原凭据、模型设置和环境指纹未变，临时配置已清理。见 [完整回执](acceptance/real-capabilities-0.2.4-2026-10-22.json) 和 [新版工具页面](images/ui-0.2.4/tools-final.png)。组件、状态恢复和模型能力测试通过；六个页面及窄窗口回归通过。此前的项目选择等待问题、一次未确定原因的页面切换和一次截图超时保留在回执中，不计为通过记录。

交付为 `release/Kuade Harness-0.2.4-win.zip`，本机解压入口为 `D:\K024z-1022\Kuade.exe`。本轮保留原有正在打开的 0.2.3 窗口，未自动切换用户实例。退出旧窗口后再使用新版。

打开「工具与技能」，启用所需工具。卡片直接显示正在连接、可调用的工具数量或连接问题。开关表示配置是否启用；可调用表示上游已注册工具，不代表某个任务已经成功。

连接后点击「试一试」可以把示例放入任务输入框，确认发送后才执行。原有草稿会保留。项目技能通过「用于任务」添加到当前需求，重复点击同一技能不会重复添加相同前缀。搜索、浏览器和电脑操作在执行记录中显示中文名称，展开详情仍可查看原始工具标识及返回内容。

电脑控制卡片说明当前模型是否声明图片输入。没有图片能力时，模型仍可通过可读取的窗口控件信息操作部分应用；纯图片、画布或复杂视觉定位需要另行验证。不会依据模型名称猜测图片支持。

本轮验收使用用户已配置的 Kimi K3，临时复制模型连接到隔离用户目录。实际点击工具开关和技能入口，由真实模型加载项目技能、搜索互联网、读取 Electron 官方文档，并通过 Playwright MCP 填写本机表单。独立 HTTP 服务核对随机标记和文档链接。电脑控制通过包内 qwen_computer 操作专用 Windows 窗口；独立结果文件和工具返回的 Accepted 状态同时核对。没有用模拟模型替代这些步骤。

测试结束删除临时模型配置，并比较原配置及环境指纹。测试窗口之外的桌面应用、任意网页、macOS 和跨天运行不属于本次验收范围。当前 Kimi K3 连接的工具结果提示图片未送入模型；本次电脑测试验证的是控件观察与操作，截图视觉理解仍未验证。
