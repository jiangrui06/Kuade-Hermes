# 回复排版与代码复制

[繁體中文](REPLIES.zh-TW.md) · [English](REPLIES.en.md)

0.1.13 将模型回复显示为可阅读的 Markdown：标题、段落、嵌套列表、只读任务清单、表格、引用、行内代码和代码块。代码块显示语言与“复制代码”按钮，保留缩进、中文及空行；复制失败时可重试。长代码和宽表格在自身区域滚动。

流式生成和重启后的历史消息复用同一展示组件。复制期间内容继续生成时，旧请求的成功提示不会覆盖新代码状态。用户输入与工具原始结果仍按原文显示；展示层不修改 Harness 记录、任务状态或模型请求。

点击 HTTP/HTTPS 链接时通过桌面接口交给系统浏览器；主进程再次验证协议。其他路径显示为文字，尚未提供本地文件跳转。模型 HTML 不作为页面元素执行，远程图片显示替代文字，不自动加载。代码语言标签用于辨识，本版未加入语法高亮。

## 复用与模块边界

使用 [react-markdown 10.1.0](https://github.com/remarkjs/react-markdown) 和 [remark-gfm 4.0.1](https://github.com/remarkjs/remark-gfm)。两者为 MIT，react-markdown 声明支持 React 18 及以上；与当前 React 19、Vite、ESM 构建兼容。固定版本及传递依赖写入锁文件，版权声明已补充。使用默认解析和 URL 过滤，不引入原始 HTML 插件。

展示组件位于 `src/renderer/components/MessageMarkdown.tsx`，样式单独存放；`src/shared/message-url.ts` 由渲染层和主进程共用。复制和打开网页复用已有 IPC 桥与 Electron API，不添加新的 Agent 工具或执行调度器。

## 验收

125 项应用测试、22 项验收工具测试、类型检查与构建通过。新增 8 项测试覆盖排版、代码复制、失败重试、流式更新竞态、协议边界、HTML／图片处理，以及保存和实时回复的接入。

真实 Electron 流程使用本地受控 SSE 服务，验证未闭合代码块、完整回复、真实系统剪贴板、窄窗口和重启后同一历史回复，重启不新增模型请求。网页打开验收核对完整 IPC 路径，系统浏览器启动函数使用测试替身，未把它算作真实外部浏览器验收。原剪贴板各格式仅在内存中保存并恢复；独立配置不读取用户 Key。[发行与验收记录](acceptance/replies-0.1.13-2026-10-22.json)。
