型別檢查、正式建置與 44 項自動化測試通過。新增元件涵蓋名稱／目錄搜尋、篩選、空白輸入、儲存失敗保留草稿、重複提交防護及 Escape 取消。開發版品牌／模型／重新命名／重啟繼續流程通過（21.2 秒），證據：建置快取 `.cache/default-models-b3bd6dea-1a35-4c72-9b63-44acdf06d03c`；檢查實際請求中的 `system` 與推理模型使用的 `developer` 角色。初次冷快取失敗及後續僅檢查 `system` 的測試斷言失敗均已修正，不計為通過。

打包版四項真實 Electron 流程全部通過（約 1.6 分鐘）：品牌／模型／改名恢復 21.7 秒、終端／Git／MCP／問答 37.9 秒、右鍵編輯選單 7.6 秒、計畫與停止／中斷恢復 25.2 秒。證據分別為建置快取 `.cache/default-models-bca8a83d-5996-4270-a47a-0191c4b4a7e7`、`.cache/e2e-50284779-ece0-4e40-95e3-ce3ccbe1c2be`、`.cache/task-progress-b01e52ca-99f3-45de-9c63-62454e317fda`。打包 EXE 的 ProductName 與 FileDescription 均為 Kuade Harness，ProductVersion 為 0.1.5.0；獨立身分擴充包含於解包資源中。驗收使用受控模型回應與真實引擎、工具及桌面視窗，不代表跨日執行或真實模型大型專案能力已通過。

## 0.1.4 工作計畫與中斷後繼續

2026-10-14：沿用上游 `todo_write`、`todos` 投影與持久化事件，新增獨立進度推導模組及步驟面板。區分等待回答、等待核准、執行中、已停止、已中斷、執行出錯、輸出上限與本輪結束；未完成計畫保留繼續入口。按鈕傳送可見的新請求，附上前一輪計畫，在原對話中要求先核對檔案與測試，不自動重播命令。新一輪由上游清空舊計畫後再更新。

41 項自動化測試、型別檢查與正式建置通過。新增元件測試及狀態邊界涵蓋：模型結尾文字不作為成功證據、本輪結束但計畫未完成、取消／中斷／錯誤／上限、等待狀態、停用繼續及原計畫傳遞。

本次目標為計畫顯示及手動繼續，不代表數小時或跨日工作的穩定性已通過；計畫完成項由 Agent 回報，仍需獨立檢查檔案與測試結果。

修正桌面中斷測試發現的歷史清單遺漏：上游冷清單的 `blank` 快取可能落後於已持久化的日誌。現在針對冷快取標為空白的工作，以最多 4 路並行讀取 `session/projections` 核實後再隱藏；讀取失敗保留入口，避免把未知當成空白。未更動上游持久化格式或另建資料庫。


開發版 4 項真實 Electron 流程全部通過（約 1.7 分鐘）：預設工作區／模型切換 20.0 秒、原有工具流程 43.5 秒、原生選單 8.5 秒、工作計畫與兩種恢復路徑 29.1 秒。新增流程實際執行 `todo_write` 與檔案寫入，分別驗證手動停止後重啟、執行中結束後重啟，在同一對話繼續並獨立檢查兩份檔案、歷史上下文及計畫從 1/2 到 2/2。證據：建置快取 `.cache/task-progress-e310f76d-644d-469d-a2b4-0374a31fe440`。模型回應來自受控介面；先前因測試入口選擇、工作定位及快取空白問題未通過的執行不列為通過。


打包版四項流程均有通過紀錄：預設工作區與模型切換 18.0 秒、原生選單 7.0 秒、計畫與停止／中斷恢復 26.0 秒，證據 `.cache/task-progress-4c8a0bf3-53ac-42f6-9dcd-88f66f926dfe`；原有工具流程單獨重跑通過 45.2 秒，證據 `.cache/e2e-a8ecacbd-bd21-4fb9-b895-a17ec926667b`。工具流程首輪出現腳本外的「你好」輸入與頁面切換，第二輪停在截圖階段；兩輪均不列為通過。為共用桌面補上截圖前恢復測試視窗後重跑通過，產品程式碼未因此修改。

正常使用者設定的啟動檢查通過：應用程式版本 0.1.4，服務商清單回傳 18 個模型，憑據檔案升級前後的摘要一致；未重新填寫或更換 Key。證據 `.cache/startup-0.1.4-d71cf7df-9669-4c36-880e-f319b1e27689/acceptance.json`。本次未新增外部模型推理驗收。安裝包與 ZIP 已複製至 `release`，並逐一核對原始檔與副本的 SHA-256，詳見 `release/SHA256SUMS-0.1.4.txt`。

30 項自動化測試、型別檢查及建置通過。開發版 3 項桌面流程通過（合計約 1 分鐘）：預設工作區 16.6 秒、原有工具流程 37.1 秒、右鍵選單 6.8 秒。新流程核驗不開啟目錄選擇器即可實際寫檔、完整清單包含未勾選模型、切換後實際模型與 `high` / 關閉檔位 `none` 參數，以及重啟後工作區身份與思考選擇。證據：建置快取 `.cache/default-models-8fbe6d00-149c-496d-8a05-9b1b083f546c`、`.cache/e2e-51b4a778-272c-49af-b677-e3b5337102f4`。

0.1.3 打包版三項桌面回歸通過：新增流程 17.2 秒、工具流程 36.9 秒、選單 6.9 秒。證據：`.cache/default-models-2ea588d0-1cdb-4be2-855b-b57de55bc9bf`、`.cache/e2e-76aa1aae-bd65-4a1d-b1c2-b6fdc291a19c`。安裝包及 ZIP 複製後 SHA-256 一致，見 `release/SHA256SUMS-0.1.3.txt`。

真實 Ollama 驗收通過（腳本退出碼 0）：對話目錄回傳 18 個模型，切換另一模型後回到 `kimi-k3`；能力選單提供預設、關閉、低、高、最高。低檔位實際在 `D:/Kuade/默认工作区` 寫入唯一命名檔案，讀取核對正確，最後恢復空白工作與預設思考。證據：`.cache/real-workbench-34280068-d201-4eb4-a358-cffced91720d/acceptance.json` 及截圖，腳本 `scripts/accept-workbench.mjs`。早期腳本匹配舊工作及按鈕精確名稱的問題已修正，中斷執行不列為通過證據。此處只驗證 Kimi 低檔實際呼叫；可選模型並非逐一通過推理、額度與權限驗收。

## 0.1.2 自動取得模型清單

沿用上游 `llm/discoverModels`；填寫 API 位址和金鑰後自動查詢，支援搜尋、多選、重新整理及已儲存憑證。手動 ID 保留於摺疊相容入口。位址或協定改變時，不會自動向新目標傳送原連接的金鑰；過期回應被捨棄，服務端錯誤不會原樣顯示金鑰。

型別檢查、生產建置及 9 個檔案中的 25 項自動化測試通過。開發版真實 Electron 流程通過（44.5 秒），涵蓋錯誤金鑰、OpenAI / Anthropic 協定、勾選儲存、重啟後沿用金鑰查詢，以及檔案、終端、MCP、審批與取消。證據：建置快取 `.cache/e2e-7a81d616-819d-4ac4-ae60-d4c7f733c9e7`。服務商回傳清單不代表每個模型的推理與工具呼叫均已實測。

打包版兩項桌面回歸通過（共 50.5 秒）：完整流程 41.1 秒、原生選單 7.2 秒。證據：建置快取 `.cache/e2e-d9521f88-9677-4d02-a0e9-ed1325336cbb`。交付檔案已複製並核對 SHA-256，見 `release/SHA256SUMS-0.1.2.txt`。

真實 Ollama Cloud 驗收通過：以已儲存的金鑰取得 18 個模型；`kimi-k3` 在獨立臨時專案建立 `sum.mjs`、`sum.test.mjs` 並執行測試，另獨立核驗正常、空陣列、負數與無效輸入。證據：建置快取 `.cache/real-model-f8e8356b-2a46-4a57-804e-e3ba99e2f54b` 的 `discovery.json`、`acceptance.json` 及截圖。首次請求發現網站根位址與模型 ID 拼寫不符；依 [Ollama 官方說明](https://github.com/ollama/ollama/blob/main/docs/api/openai-compatibility.mdx) 修正為 `https://ollama.com/v1` 和清單回傳的 `kimi-k3` 後通過，金鑰保持原值。

## 0.1.1 右鍵選單修復

補齊原生編輯選單，涵蓋模型設定、密碼、對話與 MCP 輸入欄位。沿用 Electron 編輯動作和 Chromium 能力旗標，不向介面暴露剪貼簿讀取介面。新增 3 項測試，總計 20 項自動化測試、型別檢查和建置通過。真實桌面測試驗證右鍵事件、原生選單彈出、原生貼上動作與實際輸入值，以及 Ctrl+V 和復原。密碼欄位只使用測試值；剪貼簿內容僅在記憶體暫存和恢復，不寫入紀錄或檔案。

0.1.1 打包版原生選單回歸通過（10.8 秒），完整桌面流程通過（34.8 秒），並確認模型連接於重啟後保留。證據：建置快取 `.cache/e2e-dc54c586-ab95-4d1f-b94e-b8fb234ec2d5`；交付校驗值：`release/SHA256SUMS-0.1.1.txt`。`scripts/accept-model.mjs` 僅手動執行，缺少完整模型連接時不傳送模型請求。

## 待驗收

0.1.2 已通過上述 Ollama Cloud 小型程式開發工作；其他模型、服務商、大型專案、自主迭代及數小時／跨日穩定性仍待驗收。已提供背景執行、歷史儲存、事件重連與停止入口；退出後不會原地恢復已終止進程。

瀏覽器 MCP、個別搜尋服務和自訂 Skills 尚未逐項實測。NSIS 安裝、卸載與升級流程尚未執行；已驗收打包應用程式本身。本機網頁版留待後續階段。

自解壓縮 EXE 便攜包於本機超過 180 秒啟動測試時限，因此交付改用 ZIP，完整解壓縮一次後直接執行。

## 重現與資料

執行 `node scripts/windows.mjs test`、`typecheck`、`build` 或 `test:e2e`。打包版驗收前將 `KUADE_TEST_EXECUTABLE` 設為 `Kuade.exe` 絕對路徑。使用者資料位於 Electron 使用者資料目錄的 `harness` 子目錄；測試用 `KUADE_USER_DATA` 隔離。含憑證的資料目錄不應上傳至儲存庫。
