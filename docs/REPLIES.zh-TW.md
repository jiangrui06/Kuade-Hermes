# 回覆排版與程式碼複製

[简体中文](REPLIES.zh-CN.md) · [English](REPLIES.en.md)

0.1.13 提供 Markdown 標題、段落、巢狀列表、唯讀工作清單、表格、引用、行內程式碼及程式碼區塊。區塊顯示語言與複製按鈕，保留縮排、中文及空行；複製失敗可重試。長程式碼和寬表格在自身區域捲動。

串流生成與重啟後的歷史訊息共用展示元件。生成期間內容改變時，舊複製請求不會覆蓋新內容狀態。使用者輸入及工具結果保留原文；展示層不修改 Harness 記錄、任務狀態或模型請求。

HTTP/HTTPS 連結經主程序再次驗證後，交由系統瀏覽器開啟。其他路徑顯示為文字，尚未提供本地檔案跳轉。HTML 不作為頁面元素執行，遠端圖片只顯示替代文字。語言標籤用於辨識，本版未加入語法高亮。

## 元件與驗收

採用 [react-markdown 10.1.0](https://github.com/remarkjs/react-markdown) 及 [remark-gfm 4.0.1](https://github.com/remarkjs/remark-gfm)，兩者為 MIT；前者支援 React 18 及以上，與目前 React 19、Vite、ESM 相容。版本與依賴已鎖定，版權聲明已補充，未加入原始 HTML 外掛。

`MessageMarkdown.tsx` 和獨立樣式負責展示，`message-url.ts` 共用網址驗證；複製與連結使用既有 IPC 和 Electron API，不新增 Agent 工具或排程器。

125 項應用測試、22 項驗收工具測試、型別檢查與建置通過。新增 8 項測試涵蓋排版、複製、錯誤重試、串流競態、協定邊界、HTML／圖片處理與訊息接入。

真實 Electron 流程使用本地受控 SSE，驗證未閉合程式碼、系統剪貼簿、窄視窗及同一歷史訊息重啟還原，未新增模型請求。網頁連結測試核對完整 IPC，但系統瀏覽器啟動使用測試替身；不算真實外部瀏覽器驗收。原剪貼簿格式只在記憶體保存及還原，隔離設定不讀取使用者 Key。[發行與驗收記錄](acceptance/replies-0.1.13-2026-10-22.json)。
