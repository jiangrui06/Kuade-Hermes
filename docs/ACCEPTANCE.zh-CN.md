## 0.1.4 任务计划与中断后继续

2026-10-14：复用上游 `todo_write`、`todos` 投影与持久化事件，新增独立进度推导模块和步骤面板。区分等待回答、等待确认、执行中、已停止、已中断、执行出错、输出上限与本轮结束；未完成计划保留继续入口。继续按钮发送可见的新请求，附带上轮计划，在原会话中要求先核对文件与测试，不自动重放命令。新轮次由上游清空旧计划后重新更新。

41 项自动化测试、类型检查和生产构建通过。新增组件测试及状态边界覆盖：模型结束文本不充当成功证据、本轮结束但计划未完成、取消/中断/错误/上限、等待状态、禁用继续和原计划传递。

本次验收目标是计划显示与手动继续，不代表数小时或跨天任务稳定性已经通过；计划完成项由 Agent 报告，仍需独立检查文件和测试结果。

修复桌面中断测试发现的历史列表遗漏：上游冷列表的 `blank` 缓存可能落后于已持久化的日志。现在对冷缓存中标为空白的任务，以最多 4 路并发读取 `session/projections` 核实后再隐藏；读取失败保留任务入口，避免把未知当空白。未改动上游持久化格式或另建数据库。

## 0.1.0 基线验证

- TypeScript 类型检查和生产构建通过；7 个测试文件、17 个自动化测试通过，覆盖 RPC、权限响应、环境隔离、MCP 配置、Git 恢复和界面交互。
- 开发版与打包后的 `Kuade.exe` 均通过真实 Electron 流程：界面配置模型 → 打开中文路径项目 → Agent 实际写文件 → 重启恢复记录 → 用户批准真实 PowerShell 命令 → MCP 握手、发现及实际工具调用 → 回答 Agent 问题 → 取消等待中的任务。
- 终端结果和文件内容均由测试读取核验；MCP 服务写入调用标记。退出应用后核验该服务进程已结束。
- Git 测试在临时真实仓库中验证恢复选中文件、拒绝过期 Diff、保留其他文件的修改。
- 打包输出包含自有图标、Kuade 产品名称、安装包与 ZIP 便携包。安装包无代码签名。
- ZIP 完整解压通过（21,341 个文件）；解压后的应用再次通过整套桌面回归（47.3 秒）。交付文件复制到 `release` 后，SHA-256 与构建产物一致；校验值保存在 `release/SHA256SUMS.txt`。
- 开发前后 Machine/User 环境变量比较均无变化。未修改系统 PATH。

桌面测试使用本机脚本化模型接口，**真实引擎、工具、文件系统和窗口均实际运行**；仅模型响应受控、文件夹选择对话框返回测试路径。它验证产品集成，不验证外部模型的推理质量。打包后回归证据目录后缀为 `.cache/e2e-8c7c22b5-307d-4e36-87e5-11a849661ca7`，位于 Windows 构建缓存，包含截图和测试接口请求。

ZIP 回归证据：同一构建缓存中的 `.cache/e2e-ea187755-685e-4f2f-877f-0d01ab5f3acf`。界面截图：[工作台](images/workbench.png)。

## 待验收和边界

- 真实厂商模型：0.1.2 已通过上述 Ollama Cloud 小型编程任务，其他模型、服务商与更大任务仍待逐项验收。
- 数小时、跨天、大项目和自主迭代：具备后台执行、历史保存、事件重连及停止入口，持续稳定性和成功率尚待长时间实测。退出后保留记录，已终止进程不会原地恢复。
- Playwright MCP 浏览器操作、各搜索服务、用户自定义 Skills：保留接入能力，未将示例 MCP 的通过扩大为所有扩展已验收。
- NSIS 安装向导、卸载和升级流程尚未在用户系统中执行；已验收的是打包应用本身。
- 自解压 EXE 便携包在本机解压启动超过 180 秒测试限时，因此正式交付使用 ZIP，解压一次后直接启动。
- 本机网页版属于后续阶段；本次只交付 Windows 桌面版。

## 复现

从源码执行 `node scripts/windows.mjs test`、`node scripts/windows.mjs typecheck`、`node scripts/windows.mjs build`。开发版验收使用 `node scripts/windows.mjs test:e2e`；验收打包版时先设置进程环境变量 `KUADE_TEST_EXECUTABLE` 为其 `Kuade.exe` 的绝对路径。

应用会话和模型设置保存在 Electron 用户数据目录的 `harness` 子目录；测试通过 `KUADE_USER_DATA` 使用独立临时目录。请勿将含凭据的用户数据目录上传到仓库。
