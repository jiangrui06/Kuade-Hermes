## 待验收和边界

- 真实厂商模型：0.1.2 已通过上述 Ollama Cloud 小型编程任务，其他模型、服务商与更大任务仍待逐项验收。
- 数小时、跨天、大项目和自主迭代：具备后台执行、历史保存、事件重连及停止入口，持续稳定性和成功率尚待长时间实测。退出后保留记录，已终止进程不会原地恢复。
- Playwright MCP 浏览器操作、各搜索服务、用户自定义 Skills：保留接入能力，未将示例 MCP 的通过扩大为所有扩展已验收。
- NSIS 安装向导、卸载和升级流程尚未在用户系统中执行；已验收的是打包应用本身。
- 自解压 EXE 便携包在本机解压启动超过 180 秒测试限时，因此正式交付使用 ZIP，解压一次后直接启动。
- 本机网页版属于后续阶段；本次只交付 Windows 桌面版。

## 复现

从源码执行 `node scripts/windows.mjs test`、`node scripts/windows.mjs typecheck`、`node scripts/windows.mjs build`。开发版验收使用 `node scripts/windows.mjs test:e2e`；验收打包版时先设置进程环境变量 `KUADE_TEST_EXECUTABLE` 为其 `Kuade.exe` 的绝对路径。

应用会话和模型设置保存在 Electron 用户数据目录的 `harness` 子目录；测试通过 `KUADE_USER_DATA` 使用独立临时目录。请勿将含凭据的用户数据目录上传到仓库。
